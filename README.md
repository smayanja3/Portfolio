# 💻 Portfolio

The code for my personal portfolio website. Built with clean code and lots of coffee, it showcases my web development work and my love for running and stationery.

## 💡 About the Project

- **My Projects:** From interactive web apps to client sites.
- **My Tech Stack:** The tools and languages I use every day.
- **A Little Fun:** Because developers who run (and love cute notebooks) code better.

## ✨ Features

- **Responsive Design:** Looks and works well on mobile, tablet, and desktop.
- **Light and Dark Mode:** A toggle in the header, remembered between visits.
- **Projects Showcase:** Client sites and custom web tools I've built.

## 🛠️ Tech Stack

- **Languages:** JavaScript (ES6+), HTML5, CSS3
- **Tools:** VS Code, Git / GitHub
